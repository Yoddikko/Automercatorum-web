1Natura del progetto

Automercatorum è una raccolta di strumenti software open source sviluppati in via indipendente, pensati per agevolare l'esperienza di studio degli studenti dell'Università Mercatorum.

Il progetto non è ufficiale. Il manutentore non ha alcun rapporto, accordo, partnership, sponsorizzazione, approvazione o autorizzazione con:

  • Università Mercatorum (Universitas Mercatorum S.p.A.)
  • Multiversity S.p.A. e le società del gruppo
  • Qualsiasi soggetto autore o titolare dei contenuti didattici della piattaforma LMS

I marchi citati appartengono ai rispettivi titolari. Il loro uso descrittivo è effettuato ai sensi dell'art. 21 del Codice della Proprietà Industriale italiano (D.lgs. 30/2005) e nei limiti dell'uso leale del marchio.

2Cosa fanno gli strumenti

Gli strumenti automatizzano operazioni che l'utente potrebbe svolgere manualmente, mediante chiamate alle stesse API esposte dal portale LMS al browser dell'utente autenticato:

  • Downloader Dispense scarica i PDF a cui l'utente ha titolo di accesso tramite il proprio account.
  • Video Export salva localmente le video-lezioni cui l'utente ha accesso, in formato MP4, per la sola visione offline personale.
  • Risposte Quiz estrae dalle risposte rese visibili dalla piattaforma le opzioni corrette dei test di fine lezione, generando un PDF di ripasso.
  • Guarda Lezioni mantiene attiva una sessione di visione delle video-lezioni rispettando la cadenza temporale richiesta dalla piattaforma.

Tutti gli strumenti operano esclusivamente in locale sul computer dell'utente. Nessun dato dell'utente transita per server gestiti dal manutentore: le sole connessioni di rete sono dirette ai server ufficiali del portale Mercatorum (*.multiversity.click) per autenticazione e per il recupero dei contenuti a cui l'utente ha titolo di accesso.

7Privacy e dati

Gli strumenti non raccolgono né trasmettono alcun dato personale a server gestiti dal manutentore. Non è presente alcuna telemetria, alcun servizio di analytics e alcun tracker di terze parti.

Sul dispositivo dell'utente vengono memorizzati esclusivamente in locale:

  • Le credenziali LMS, in un file creds.json con permessi di accesso ristretti al solo proprietario (modalità 0600). La memorizzazione delle credenziali è opzionale: l'utente può scegliere di reinserirle a ogni avvio.
  • Log diagnostici di esecuzione, sanitizzati per non includere password, token di sessione o URL completi.
  • I file scaricati o generati (PDF dispense, video MP4, PDF risposte quiz) nelle cartelle scelte dall'utente.

Le sole richieste di rete vengono effettuate verso i server del portale Mercatorum (*.multiversity.click) per autenticazione e per il recupero dei contenuti, e verso GitHub (github.com, api.github.com) per mostrare la versione corrente sul sito. Nessun'altra connessione esce dal computer dell'utente.

Le funzioni di "Segnala un errore" producono un pacchetto diagnostico salvato localmente: l'invio è a discrezione dell'utente, che decide se allegarlo o meno alla segnalazione su GitHub.
